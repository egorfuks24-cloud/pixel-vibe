# Delivery gate

- Planning: each beat has point, action, result, hold, source/license, transition and unique asset. Validate the sheet; unresolved factual claims do not enter voiceover.
- Native: no expression errors; named editable layers; nested comp and footage lengths cover exits; trim keyframes use valid property match names; no discarded dirty project.
- Export: actual 9:16 dimensions/frame rate/duration, full file decode, no blank tails. Sampling cannot prove continuous playback.
- Visual: at least one settled frame per scene, before/during/after every cut, all short-lived values/clicks at full size. Check collisions, pixel edges, Cyrillic, safe margins, pointer targets, foreground/background separation and source attribution. Calendar dates may not roll backwards or expose a later leaf too early.
- Temporal: watch at delivery speed when possible. Check easing, cadence, rhythmic repetition, holds and continuation. If playback unavailable, explicitly state it and inspect denser temporal samples. A technically valid export can still be rejected.
- Voice: use actual recording, adjust beat timing, inspect final audio track and listen to complete result. Silent templates are not voice-synced films.
- Deliver: MP4 + native AEP + timed script + beat/source manifest. Keep user's materials outside public skill. Ask for review only after concrete output exists; do not label sampled or unreviewed work “identical to the reference”.
